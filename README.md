# 🏧 Basic ATM Machine (C# Console Application)

## 📌 Project Overview
This is a **beginner-level ATM Machine console application** built using **C#**.  
The project is designed to practice Object-Oriented Programming concepts, input validation, and basic authentication logic.

---

## ✨ Features
- Create a new bank account
- Prevent creation of duplicate account numbers
- Login using account number and PIN
- Withdraw money
- Deposit money
- Check account balance
- Logout functionality

---

## 🛠️ Technologies Used
- C#
- .NET (Console Application)

---

## 📂 Project Structure
- `Program.cs` – Main program flow and menus  
- `Customer.cs` – Customer-related data and operations  
- `Authentication.cs` – Login authentication logic  
- `CheckValidation.cs` – Input validation for account number, PIN, and phone number  

---

## ▶️ How to Run
1. Open the project in Visual Studio  
2. Run the application  
3. Follow the on-screen instructions in the console  

---

## 🎯 Learning Objectives
- Understanding classes and objects
- Working with lists and methods
- Validating user input
- Implementing simple authentication logic
